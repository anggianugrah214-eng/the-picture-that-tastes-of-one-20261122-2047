Entry for the [make.fun bounty](https://make.fun/bounty/the-picture-that-tastes-of-one-20261122-2047) — one hero ingredient, one look and you can taste it.

The image is a single perfectly ripe mango, halved: vivid orange flesh
glistening with juice, a few droplets catching warm side light, on clean
dark slate. Macro food-photography style, close-up, filling the frame —
no text, no hands, nothing else on the plate. One ingredient, unmistakable.

`main.ts` (Node 22, standard library only) reads `entry.png` next to itself,
validates its PNG signature, and writes the identical bytes to
`$MAKEFUN_OUTPUT_DIR/entry.png` (falling back to `./out/entry.png`).
